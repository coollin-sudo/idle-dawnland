# 放置冒險：晨曦大陸

一款原創的網頁放置 RPG。選一個職業，角色就會自動打怪、升級、撿裝備，關掉網頁也會繼續累積收益。

## 玩法

- **四種職業**：劍士（血厚）、遊俠（攻速與暴擊）、法師（無視防禦的爆發）、祭司（自我治療）。每個職業在 Lv.1 / 15 / 35 各學會一個自動施放的技能。
- **八個區域**：每區擊殺 25 隻怪物後可以挑戰首領，打倒首領就會解鎖下一區。最後的「混沌深淵」是無盡挑戰，一層比一層強。
- **裝備**：7 個部位、5 種稀有度（普通／精良／稀有／史詩／傳說），稀有度越高附加的詞綴越多。
- **強化**：+0～+3 必定成功；+7 以上失敗會讓裝備碎裂，可以用保護卷軸保住裝備。
- **離線收益**：離開時以線上效率的 60% 計算，最多 8 小時。
- **存檔**：進度存在瀏覽器裡（localStorage），可以在「設定」匯出／匯入存檔碼，在不同裝置之間轉移。

## 本機執行

純 HTML/CSS/JS，不需要安裝任何東西：

```bash
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。

## 部署（GitHub Pages）

Repo 的 Settings → Pages → Source 選 `main` 分支、根目錄 `/`，幾分鐘後就能用 `https://<帳號>.github.io/<repo 名稱>/` 遊玩，把網址分享給朋友即可。

## 美術圖

目前角色和怪物都用 emoji 顯示。圖片清單和生圖 prompt 在 [ART_PROMPTS.md](ART_PROMPTS.md)，把圖放進 `assets/` 對應的資料夾後，遊戲會自動換成圖片。

## 專案結構

```
index.html        頁面骨架
css/style.css     樣式
js/data.js        職業、區域、怪物、裝備、商店等遊戲資料（調整數值改這裡）
js/game.js        遊戲邏輯、戰鬥、存檔與畫面
assets/           角色、怪物、背景圖（可選）
```
