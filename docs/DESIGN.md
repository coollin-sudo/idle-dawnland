# 放置冒險：晨曦大陸 — 遊戲設計文件 v2

## 0. 願景

一款「掛著就有進度、打開就有決策」的網頁放置 RPG。短期（每次上線 5 分鐘）有裝備、強化、技能配置的決策；中期（數天）有區域推進、轉職、天賦、寵物；長期（數週）有三種難度、無盡之塔、轉生與星魂天賦、圖鑑與成就收集。

## 1. 世界觀

晨曦大陸的「永晝水晶」被暮影之主擊碎，八塊碎片散落各地，汙染了守護各區的生物。玩家是曙光騎士團的新進守護者，在騎士隊長**艾莉亞**的帶領下收復碎片。

| NPC | 職責 |
|---|---|
| 艾莉亞（騎士隊長） | 主線劇情、轉職導師 |
| 葛倫（老鐵匠） | 鍛造屋：強化、重鑄、分解、打造 |
| 米菈（學者） | 怪物圖鑑、成就 |
| 波波（寵物商人） | 寵物孵化與養成 |
| 薩爾（旅行商人） | 商店、限時商品 |

## 2. 架構

```
src/
  core/      純邏輯，不碰 DOM：亂數、事件匯流排、公式、狀態型別、遊戲主類別
  data/      內容資料：職業、技能、天賦、區域、怪物、詞綴、裝備、傳說、套裝、寵物、任務、成就、劇情
  systems/   系統：數值、戰鬥、狀態異常、掉落、背包、鍛造、成長、關卡、副本、高塔、寵物、任務、成就、圖鑑、轉生、離線
  render/    Canvas 戰鬥場景：程式繪製角色/怪物、粒子、飄字、視差背景、鏡頭震動
  audio/     WebAudio 程式合成音效與配樂
  ui/        Preact 介面元件
  save/      存檔序列化、版本遷移、匯出匯入
```

原則：
- **core / systems 可在 Node 中無畫面執行**，平衡模擬與離線收益都直接跑真的戰鬥邏輯。
- **單向資料流**：系統修改 `GameState` 並發出事件 → 渲染器訂閱事件播動畫 → UI 以節流的 signal 重繪。
- **固定時間步長**：邏輯 100ms 一步，渲染用 requestAnimationFrame 插值。
- **內容資料驅動**：新增怪物、裝備、技能只需改 data。

## 3. 數值系統

### 3.1 屬性
| 主屬性 | 效果 |
|---|---|
| 力量 STR | 物攻 +2、生命 +3 |
| 敏捷 DEX | 物攻 +1、暴擊 +0.04%、迴避 +1、攻速 +0.05% |
| 智力 INT | 魔攻 +2.5、魔力 +3、魔抗 +0.5 |
| 體質 VIT | 生命 +12、防禦 +0.6 |

職業會額外換算主屬性（遊俠：每點 DEX 再 +1.5 物攻）。

### 3.2 修正值
所有加成表示為 `{ stat, kind: flat | inc | more, value }`：
`最終值 = (基礎 + Σflat) × (1 + Σinc) × Π(1 + more)`

### 3.3 戰鬥公式
- 防禦減傷 `def / (def + 40 × 攻擊者等級 + 200)`，上限 75%；魔抗同理對魔法傷害。
- 迴避率 `eva / (eva + 30 × 攻擊者等級 + 100)`，上限 40%。
- 暴擊基礎 5%、暴傷 150%。
- 攻擊間隔 `基礎間隔 / (1 + 攻速%)`；冷卻以 `(1 + 冷卻縮減%)` 倍速流逝。
- 元素：物理、火、冰、雷、聖、暗。怪物有各元素抗性（-50% 弱點 ～ +75%）。

### 3.4 狀態異常
| 狀態 | 來源 | 效果 |
|---|---|---|
| 燃燒 | 火 | 每秒造成命中傷害 20%，持續 3 秒，可疊 3 層 |
| 冰緩 / 冰凍 | 冰 | 攻速 -30%；冰緩疊滿 3 層變冰凍 1.5 秒 |
| 感電 | 雷 | 受到傷害 +15%，4 秒 |
| 流血 | 特定物理技能 | 每秒 15%，5 秒，可疊 5 層 |
| 中毒 | 暗 | 每秒 10%，6 秒，可疊 10 層 |
| 暈眩 | 特定技能 | 無法行動 1 秒 |
| 護盾 | 技能/首領 | 吸收傷害 |

## 4. 職業

| 基礎職業 | Lv.30 轉職 A | Lv.30 轉職 B |
|---|---|---|
| 劍士（物理近戰、坦） | 狂戰士（吸血、狂暴、範圍） | 聖騎士（護盾、反擊、聖傷） |
| 遊俠（物理遠程、暴擊） | 神射手（單體爆發、穿透） | 毒影刺客（中毒、流血、連擊） |
| 法師（魔法、元素） | 元素使（火冰雷連鎖） | 暗咒師（暗系詛咒、召喚） |
| 祭司（魔法、治療） | 大主教（聖光、治癒、增益） | 審判者（聖錘、暈眩、近戰魔攻） |

- 每職業 4 個基礎技能，轉職再解鎖 3 個（含 1 個終極技）。
- **技能欄** 4 格（Lv.1/5/15/30 解鎖），可自訂施放優先順序。
- **技能點**：每級 1 點，技能最高 10 級。
- **天賦樹**：每個職業一棵（攻擊／防禦／輔助三排，約 18 節點），每 3 級 1 點。

## 5. 區域與關卡

8 區 × 10 關，每關 5 波；第 10 關最後一波是首領戰（限時 60 秒）。

| # | 區域 | 怪物等級 | 主元素 |
|---|---|---|---|
| 1 | 晨露草原 | 1–10 | 物理 |
| 2 | 迷霧森林 | 11–20 | 暗/毒 |
| 3 | 遺忘礦坑 | 21–30 | 物理 |
| 4 | 赤沙遺跡 | 31–40 | 火 |
| 5 | 霜語山脈 | 41–50 | 冰 |
| 6 | 熔心火山 | 51–60 | 火 |
| 7 | 雷鳴天城 | 61–70 | 雷 |
| 8 | 暮影深淵 | 71–80 | 暗 |

- **難度**：普通 → 惡夢（怪物 +30 級）→ 地獄（+60 級）。
- **推進模式**：自動推進 / 停留刷怪；首領失敗自動退回上一關刷怪。
- **精英怪**：機率出現，帶 1–2 個詞綴（堅韌、狂暴、吸血、迅捷、火焰、冰霜、護盾、反射）。
- **首領機制**：蓄力重擊、召喚小怪、狂暴（低血量攻速提升）、護盾階段。

## 6. 裝備

- **部位**：武器、副手、頭盔、盔甲、手套、腰帶、鞋子、項鍊、戒指 ×2。
- **稀有度**：普通、優良、稀有、史詩、傳說、神話（神話只在惡夢以上首領與高塔出現）。
- **詞綴**：依物品等級分級，數值隨機並顯示品質 %。
- **傳說裝備**：固定名稱與特殊能力（觸發型：命中、暴擊、擊殺、受擊、開戰）。
- **套裝**：每個職業 1 套 + 2 套通用，2 件／4 件效果。
- **鍛造屋**：
  - 強化：最高 +20；+5～+9 失敗會掉 1 級，+10 以上失敗會碎裂，可用保護卷軸
  - 重鑄：重骰 1 條詞綴，可鎖定其他詞綴
  - 分解：獲得精華、強化石、傳說碎片
  - 打造：指定部位，保底稀有；50 傳說碎片可打造指定部位的傳說
- **自動分解規則**：依稀有度，保留比目前裝備更好的。

## 7. 其他玩法

- **每日副本**（每日 2 次，可用寶石加購）：黃金洞窟（金幣）、精煉礦脈（強化石）、試煉神殿（經驗）。60 秒內打越多越好。
- **無盡之塔**：每層一隻強化首領，限時 45 秒；每層給寶石，每 10 層寶箱（套裝機率）。
- **寵物**：12 種，蛋孵化需要現實時間；出戰寵物會攻擊，所有寵物提供收藏加成；吃飼料升級，重複寵物升星。
- **主線任務**：每區一章，附劇情對話；完成給金幣、寶石、裝備。
- **每日任務**：每日 5 個，全部完成開每日寶箱。
- **成就**：計數型分級成就，給永久加成 + 寶石。
- **怪物圖鑑**：每種怪物擊殺 50/500/5000 隻，各給全傷害 +0.5%。
- **轉生**：通關第 5 區後解鎖。依最高關卡獲得星魂，用於星魂天賦（攻擊、生命、經驗、金幣、掉寶、離線上限、起始區域、強化成功率…）。轉生重置等級、關卡、金幣、技能與天賦；保留裝備、寵物、寶石、成就、圖鑑。
- **祝福**：30 分鐘的經驗、金幣、掉寶加成。

## 9. 離線

離線時用真實戰鬥邏輯模擬目前關卡 3 分鐘取得效率，再外推到離線時間（基礎上限 12 小時，可用星魂提升），收益為線上的 70%。掉落的裝備依自動分解規則處理，並顯示離線報告。
