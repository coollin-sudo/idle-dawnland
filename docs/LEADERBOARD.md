# 排行榜設定（Supabase）

遊戲本身是靜態網頁，排行榜的成績存在 Supabase（免費方案即可）。沒設定前，遊戲不會顯示「排行」分頁。

## 一、建立專案（約 5 分鐘）

1. 到 <https://supabase.com> 註冊並登入，按 **New project**。
   - 名稱隨意（例如 `dawnland`），區域選 **Northeast Asia (Tokyo)** 或 **Singapore**，資料庫密碼自己保存好（遊戲用不到）。
2. 建好後左側選 **SQL Editor** → **New query**，把 [`supabase/leaderboard.sql`](../supabase/leaderboard.sql) 整份貼上，按 **Run**。看到 `Success` 就完成了（可以重複執行）。
3. 左側 **Project Settings → API**（或首頁的 **Connect**），找到：
   - **Project URL**：像 `https://abcdefgh.supabase.co`
   - **anon public key**（或 **Publishable key**）：一長串 `eyJ...` 或 `sb_publishable_...`
4. 把這兩個值交給開發者，填進 `src/online/config.ts` 後重新部署。

> anon key 本來就是公開的（會出現在網頁原始碼裡）。真正的權限由 SQL 裡的函式與 RLS 控制：瀏覽器只能呼叫 `lb_submit`、`lb_board`、`lb_leave`，不能直接讀寫資料表。
> **service_role key 絕對不要給任何人、也不要放進程式碼。**

## 二、排行榜內容

| 榜 | 比什麼 | 說明 |
|---|---|---|
| 冒險進度 | 最遠關卡（難度 × 80 + 關卡） | 只會往上，不因轉生倒退 |
| 首領速通 | 打倒區域首領的秒數 | 英雄等級不高於首領時才算，比的是打法（配合首領機制） |
| 本週高塔 | 這週無盡之塔通過的最高層 | 台灣時間週一 00:00 換週，週次由伺服器決定 |
| 戰力 | 目前戰力 | 取最新值 |

每個榜都能依職業篩選。玩家要在「排行」分頁按「加入排行榜」才會上傳（只上傳角色名、職業、等級、轉生次數與成績），之後每 10 分鐘、打破紀錄或打倒區域首領時自動上傳；可隨時退出並刪除伺服器上的紀錄。

## 三、防作弊

網頁遊戲的存檔與程式都在玩家的電腦上，**沒辦法百分之百防止作弊**；業界做法是多層把關，讓作弊比正常玩還麻煩，並把可疑紀錄挑出來給人審核。本遊戲分三層：

| 層 | 在哪裡 | 擋什麼 | 能不能被繞過 |
|---|---|---|---|
| 1. 存檔簽章 | 瀏覽器（`src/save/sign.ts`） | 直接改 localStorage 或匯出的 JSON（例如把金幣、關卡改大） | 懂程式的人可以，但門檻高很多；被判定修改過的存檔照常能玩，只是不能上榜 |
| 2. 合理性檢查 | 伺服器（`lb_submit`） | 關卡怪物等級比曾達到的最高等級高 6 級以上；戰力超過「依等級與轉生次數」的上限；首領速通不是在首領等級以下打出來的 | 只能「改得像真的」 |
| 3. 成長速度檢查 | 伺服器，用**伺服器時間** | 兩次上傳之間，等級、進度、戰力、本週塔層漲得比正常玩家快 | 只能慢慢改，等於要跟正常玩家一樣花時間 |

第 2、3 層**全自動處理，不需要人工審核**：
- 漲得太快 → 不隱藏人，只把這次成績**壓回合理上限**；真的作弊跳不上去，被誤判的正常玩家之後幾次上傳會自然補上。
- 不可能的數值 → 這筆**不採計**，記一次違規；**累積 3 次自動隱藏**這個玩家。
- 首領速通不是在首領等級以下打的 → 直接不採計。
- 玩家會看到「已自動調整」或「已隱藏」的提示；每次上傳都記在 `lb_history`。

**第四層「伺服器重算驗證」（server-side re-simulation，延後到玩家變多再做）**
- 做什麼：打破首領速通紀錄時，把存檔上傳到 Supabase Edge Function，伺服器用同一套戰鬥程式自己重打約 20 次；玩家宣稱的秒數明顯比伺服器最快那次還快，就標記審核。
- 難點不在重打，而在相信存檔：要檢查點數總和、裝備詞綴是否在可能範圍、物品等級與強化上限、寵物／成就／稱號／共鳴加成。
- 需要：約一天開發；部署時由你登入一次 Supabase CLI。

## 四、管理（通常不需要）

防作弊是全自動的，平常**不用進 Supabase**。只有想了解狀況時：

- 看被調整或隱藏過的玩家：SQL Editor 執行 `select * from lb_review;`
- 手動放回某個玩家：`update lb_players set hidden = false, strikes = 0 where name = '玩家名';`
- 手動隱藏：Table Editor → `lb_players`，把 `hidden` 打勾。
- 免費專案若連續一週沒有任何請求會被暫停，到 Supabase 後台按 **Restore** 即可恢復（資料不會消失）。
